# AgriVerify AI – Sample Datasets for Testing & Demonstration

This folder provides ready-to-use sample files to evaluate the MVP features:

1. **`claims_import_sample.csv`**:
   - Used in **Insurance Portal -> Claims Management -> Import CSV**.
   - Contains batch claims across Bhopal, Sehore, and Raisen with varied crop types and loss percentages.

2. **`process_audit_sample.csv`**:
   - Used in **Insurance Portal -> Engine 3: Process Audit -> Upload Insurance Batch**.
   - Contains historical claim timelines with normal records, SLA breaches (> 21 days), and missing mandatory document flags.

3. **`farms_khasra_sample.geojson`**:
   - Contains GeoJSON polygons of verified agricultural fields in Madhya Pradesh with Khasra metadata.
